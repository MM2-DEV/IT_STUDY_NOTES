## Definition of Computer {#definition-of-computer}

> **A computer is an electronic device that accepts data as input, processes it according to a set of instructions (a program), stores data and results, and produces the result as output.**

## Characteristics of Computer {#characteristics-of-computer}

The characteristics of a computer are the qualities that make it so useful compared with manual work. The main characteristics are explained below.

### 1. Speed

A computer works at a very high speed. It can perform millions, and in modern machines billions, of operations in one second. A calculation that would take a person many hours or days can be completed by a computer in a fraction of a second.

The speed of a computer is expressed in very small units of time:

| Unit | Symbol | Value |
| --- | --- | --- |
| Millisecond | ms | 10⁻³ second (one thousandth) |
| Microsecond | µs | 10⁻⁶ second (one millionth) |
| Nanosecond | ns | 10⁻⁹ second (one billionth) |
| Picosecond | ps | 10⁻¹² second (one trillionth) |

Related measures:

1. **Clock speed** of a processor is measured in hertz (Hz), meaning cycles per second. 1 GHz (gigahertz) = 10⁹ cycles per second.
2. **MIPS** (Million Instructions Per Second) measures how many instructions a processor executes per second.
3. **FLOPS** (Floating-point Operations Per Second) is used to measure the speed of scientific computers, especially supercomputers.

### 2. Accuracy

A computer performs calculations with a very high degree of accuracy. If the input data and the program are correct, the result will be correct every time.

Errors in computer output are almost always caused by **human mistakes**, such as wrong input data or a faulty program, not by the computer itself. This principle is known as **GIGO: Garbage In, Garbage Out**. If incorrect data (garbage) is given as input, the output will also be incorrect (garbage). The term is usually credited to the early IBM programmer George Fuechsel (late 1950s).

### 3. Diligence

*Diligence* means working steadily without getting tired.

Unlike a human being, a computer does not suffer from tiredness, boredom or loss of concentration. It can perform the same task millions of times, continuously for hours, with the same speed and accuracy on the last operation as on the first.

### 4. Versatility

*Versatility* means the ability to do many different kinds of work.

Simply by running different programs, the same computer can be used to:

1. Type a letter
2. Prepare a budget
3. Play music
4. Browse the Internet
5. Draw a design
6. Solve a scientific problem

A computer can also run several programs at the same time, for example playing music while a document is being edited.

### 5. Storage Capacity (Memory)

A computer can store a very large amount of data and recall any part of it quickly and exactly. It can store:

1. Text
2. Numbers
3. Pictures
4. Audio
5. Video

Storage in a computer is of two kinds:

1. **Primary memory** (such as RAM) holds data and instructions that are being used right now.
2. **Secondary storage** (such as a hard disk, SSD or pen drive) keeps data permanently, until it is deleted.

A human being forgets information over time, but a computer keeps stored data unchanged for as long as it is stored.

Storage capacity is measured in units such as:

1. Byte (B)
2. Kilobyte (KB)
3. Megabyte (MB)
4. Gigabyte (GB)
5. Terabyte (TB)

One byte is 8 bits. In the traditional binary convention used in most examinations, 1 KB = 1024 bytes, 1 MB = 1024 KB, and so on. (Under the IEC standard, 1024 bytes is properly called a kibibyte, KiB, and 1 kB means 1000 bytes.)

### 6. Automation

Once a program and its data are given to the computer, it carries out the whole job automatically, one instruction after another, **without further human intervention**. This is possible because the program is stored in the computer's memory (the *stored-program concept*).

### 7. Reliability

A computer is reliable: given the same input and program, it always produces the same output. Modern electronic components have a long life and rarely fail, so computers can work continuously for long periods. This is why computers are trusted for critical work such as banking transactions, air-traffic control and hospital monitoring.

### 8. Logical Decision-Making

A computer can compare two values and choose what to do next depending on the result (for example, *if marks ≥ 33 then "Pass", otherwise "Fail"*). These logical operations let a computer follow different paths in a program. This is not real thinking: the computer only follows conditions written by a programmer.

### 9. Reduction in Paperwork and Cost

Records kept electronically need far less paper and can be searched, copied and shared quickly. Although buying a computer system needs a high initial investment, it reduces the cost of each transaction in the long run.
