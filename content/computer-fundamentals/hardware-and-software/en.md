A computer system is made of two parts:

1. **Hardware:** the physical machine
2. **Software:** the programs that tell the machine what to do

Neither can do any useful work without the other.

### Hardware

**Definition:** Hardware consists of the **physical parts** of a computer — the components that we can **see and touch**.

**Types of hardware (by function):**

| Type | Function | Examples |
| --- | --- | --- |
| Input devices | Enter data and instructions into the computer | Keyboard, mouse, scanner, microphone, joystick, webcam |
| Output devices | Present the processed results to the user | Monitor, printer, speaker, headphones, projector |
| Storage devices | Store data and programs | Hard disk drive (HDD), solid-state drive (SSD), pen drive |
| Internal (processing) components | Process data and connect the parts together | CPU, RAM, ROM, motherboard, graphics processing unit (GPU) |

**Types of hardware (by location):**

1. **Internal hardware:** components inside the computer case, such as the motherboard, CPU, RAM and hard disk. They are needed for the computer to work.
2. **External hardware (peripherals):** devices connected to the computer from outside, such as the monitor, keyboard, mouse, printer and scanner.

### Software

**Definition:** Software is a **set of programs** that tells the hardware what to do. A **program** is a set of instructions written to perform a particular task. Software cannot be touched; it can only be seen and used.

### Types of Software

Software is of two main types:

1. **System software**
2. **Application software**

#### 1. System Software

**Definition:** System software is the software that **operates and controls the computer hardware** and provides a platform for other software to run. It works as an **interface between the hardware and the user**. It is usually developed by the computer manufacturers.

**Examples:**

1. **Operating systems:** Windows, macOS, Linux, Unix.
2. **Device drivers:** programs that let a hardware device (such as a printer, graphics card or network adapter) work with the operating system.
3. **Language translators (language processors):** compiler, interpreter and assembler, which convert programs into machine language.
4. **Utility programs:** tools for maintaining the computer, such as antivirus, disk cleanup, backup and file compression software. (See [Installation and Utility Software](/topics/computer-maintenance/installation-and-utility-software).)

#### 2. Application Software

**Definition:** Application software is the software designed to perform a **specific task for the user**. It may be a single program or a group of programs that work together (a *software package*). It runs on top of the operating system.

**Examples:**

1. Word processor (Microsoft Word)
2. Spreadsheet (Microsoft Excel)
3. Presentation software (Microsoft PowerPoint)
4. Web browser (Google Chrome, Mozilla Firefox)
5. E-mail client (Microsoft Outlook)
6. Media player (VLC Media Player)
7. Graphics software (Adobe Photoshop)
8. Database software (Microsoft Access, MySQL)
9. Payroll software
10. Student record software
11. Inventory management software
12. Income tax software
13. Railway reservation software

#### Differences Between System Software and Application Software

| Basis | System Software | Application Software |
| --- | --- | --- |
| Purpose | Operates and controls the computer hardware | Performs specific tasks for the user |
| Position | Close to the system (hardware) | Close to the user |
| Speed | Fast | Slower |
| Design | Difficult to design and understand | Easy to design and understand |
| Interaction | Less interactive | More interactive |
| Size | Smaller | Bigger; needs more storage space |
| Language | Generally written in low-level language | Generally written in high-level language |
| Dependence | Runs independently and provides the platform | Needs system software (operating system) to run |
| Examples | Windows, Linux, device drivers, compilers | MS Word, Excel, Google Chrome, payroll software |

### Relationship Between Hardware and Software

1. Hardware and software **depend on each other**. Hardware cannot do any task without software, and software cannot run without hardware.
2. Software **directs** the hardware: it gives the instructions that the hardware carries out.
3. A combination of hardware and software forms a **usable computer system**.
4. The same hardware can do many different jobs simply by running different software.
5. Hardware is **rigid**: it is difficult to change. Software is **flexible**: it is easy to change, update or replace.

### Differences Between Hardware and Software

| Basis | Hardware | Software |
| --- | --- | --- |
| Definition | The physical parts of a computer | A set of programs that tells the hardware what to do |
| Nature | Tangible: can be seen and touched | Intangible: can be seen and used, but not touched |
| How it is made | Manufactured in factories from electronic and other materials | Developed by programmers using programming languages |
| Dependence | Cannot do any task without software | Cannot run without hardware |
| Wear | Wears out over time | Does not wear out, but may have bugs (errors) |
| If damaged | Replaced with a new part | Reinstalled or restored from a backup copy |
| Transfer | Can only be moved physically | Can be copied and transferred over a network |
| Change | Difficult to change (rigid) | Easy to change and update (flexible) |
| Viruses | Not usually infected directly, though malware can affect its operation and firmware | Can be infected by viruses and other malware |
| Common causes of failure | Dust, overheating, humidity | Bugs (programming errors), overloading, version mismatches |
| Types | Input, output, storage and internal components | System software and application software |
| Examples | Keyboard, mouse, monitor, printer, CPU, RAM, hard disk | Windows, MS Word, Excel, Google Chrome, Photoshop, MySQL |
