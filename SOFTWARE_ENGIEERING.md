# Software Engineering Learning Roadmap

## From HTML Fundamentals to Production Deployment

A structured topic checklist for learning software engineering from the
ground up. The roadmap moves from web fundamentals to frontend
development, backend development, databases, testing, security, and
deployment.

> **How to use this roadmap:** Study each section in order. Learn the
> concepts, write small examples, build the suggested projects, and move
> on when you can explain the topic and use it without following a
> tutorial step by step.

## 19. Portfolio Projects

Build projects that combine multiple sections of the roadmap.

1.  **Responsive portfolio website** --- HTML, CSS, JavaScript,
    accessibility, and deployment.
2.  **Task management application** --- React, routing, forms,
    authentication, and API integration.
3.  **REST API** --- Django REST Framework, PostgreSQL, validation,
    permissions, and API documentation.
4.  **Admin dashboard** --- React, TypeScript, reusable components,
    tables, filters, charts, and backend integration.
5.  **Full-stack application** --- React or Next.js, Django, PostgreSQL,
    authentication, file uploads, and role-based permissions.
6.  **Production deployment** --- Docker, Linux server, Nginx, HTTPS,
    CI/CD, logs, monitoring, and backups.

For each project, aim to include: - A clear README and setup
instructions - Clean and maintainable code - Input validation and error
handling - Authentication and authorization where appropriate -
Automated tests - Environment variable examples without real secrets - A
deployed version - Screenshots or a short demo

## Suggested Learning Order

1.  Web fundamentals → HTML → CSS → JavaScript
2.  Git and developer tools → TypeScript
3.  React → frontend architecture → Next.js
4.  Python → Django → Django REST Framework
5.  SQL → PostgreSQL → data modeling
6.  API design → authentication → frontend/backend integration
7.  Software architecture → testing → security
8.  Linux and networking → Docker → CI/CD
9.  Cloud hosting → production deployment → monitoring and maintenance

## Completion Criteria

You are ready to move beyond a section when you can:

-   Explain its core concepts in your own words.
-   Build a small working example without copying a complete tutorial.
-   Debug common problems independently.
-   Explain important trade-offs and when to use the technology.
-   Apply the topic in at least one practical project.

**Important:** This is a broad roadmap, not a requirement to master
every tool. Learn the fundamentals deeply, choose one primary frontend
stack and one primary backend stack, and study alternative tools only
when they solve a real problem.
