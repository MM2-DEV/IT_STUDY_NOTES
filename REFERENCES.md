# Research References and Source Guidelines

## 1. Purpose

This file defines the primary research sources and guidelines for creating educational content for this website.

The website provides comprehensive, exam-oriented Computer Science and Information Technology notes in both English and Bengali, primarily targeting Bangladesh government IT job examinations and other relevant competitive examinations.

The following websites are the primary reference sources for researching all subjects, categories, topics, and subtopics included in `TOPICS.md`.

These are general-purpose reference websites. They are not restricted to any particular subject.

Claude must actively explore these websites, discover relevant topic-specific articles, follow useful internal links, and collect information relevant to the topic being researched.

**Important:** Do not simply read the homepage and start writing. Navigate to the relevant subject and topic pages before preparing notes.

Bangladesh government IT job examination preparation.

- Subject-wise and topic-wise questions.
- MCQ questions and answers.

## 4. Source Selection and Reliability

Use each source according to its strengths.

| Source                       | Primary Use                                           |
| ---------------------------- | ----------------------------------------------------- |
| IT Job QnS                   | Bangladesh IT job examination questions and patterns  |
| TutorialsPoint               | Structured tutorials and conceptual explanations      |
| GeeksforGeeks                | Technical details, algorithms, examples, and practice |
| TpointTech                   | Structured tutorials and cross-checking explanations  |
| Programiz                    | Programming and DSA tutorials, example programs        |
| Additional reputable sources | Verification and missing information                  |

### Source priority rule (from the project owner)

The five primary websites (IT Job QnS, TutorialsPoint, GeeksforGeeks, TpointTech, Programiz) always have priority over every other source.

1. **Check first, write after.** For every subtopic, definition and comparison ("difference between …") table, search all five primary websites for that exact item and read the matching pages. Prepare the answer only after this check is done.
2. **Use their answers as the basis.** Include the points, classifications and comparison-table rows they give (in original wording). Never drop a point as "unsourced" without checking the primary websites.
3. **When one primary website has an issue, cross-check the others first.** If a primary website has a factual error, a contradiction, or an unclear or incomplete answer, check the same item on **all the other primary websites**.
4. **Other sources only when needed.** Visit any other website **only** if:
   1. the primary websites do not cover the item, or
   2. after cross-checking all the primary websites, there is still an issue or any confusion (they disagree, all are unclear, or the answer still looks wrong).

   Then use authoritative sources (official documentation, standards, textbooks, established encyclopedias) to settle it, and cite them.
5. **No issue, no extra sites.** If the primary websites answer an item correctly and agree, do not visit other sites for it.
6. **Accuracy first.** The notes are used for examination preparation, so a wrong fact costs the reader marks. Never publish a point you are not sure of; resolve every doubt as above, and report any point that remains uncertain to the project owner.

**How to check the five websites (mandatory for every topic):**

1. **Search each website separately**, one search per website (for example, a web search limited to that one domain). Never rely on a single combined search ("site A OR site B"); it silently misses pages.
2. **Do not give up after one failed attempt.** If a guessed URL returns 404, search that website for the correct page. If a page is cut off (long menus can fill the first part of a fetched page), read the rest of it.
3. **Keep a checklist** for the topic: every subtopic and comparison table × the five websites, each cell recording the page that was read or "this website has no page on it". Write the notes only when every cell is filled.
4. **Write the best answer:** combine the points, classifications, examples and table rows of all five websites into one complete, correct answer.
5. **Report** to the project owner which websites had no page for an item, and every issue found on a website and how it was resolved.

### Source verification rules

1. Do not rely on a single source for important technical claims.
2. Cross-check important definitions, algorithms, classifications, and numerical rules.
3. If sources provide conflicting information, investigate the difference.
4. Prefer technically accurate and well-supported explanations.
5. Do not blindly accept every statement from a reference website.
6. Use authoritative documentation, textbooks, and reputable educational resources when additional verification is necessary.
7. Never fabricate information, examples, references, or examination questions.
8. Record the actual sources used for each topic.

Therefore, research must consider both conceptual knowledge and examination requirements.

For each topic, where relevant:

- Identify important definitions and terminology.
- Identify frequently asked conceptual questions.
- Find previous examination questions.
- Identify repeated question patterns.
- Collect relevant numerical problems.
- Identify algorithm-based questions.
- Identify comparison-based questions.
- Identify important diagrams and flowcharts.
- Identify facts useful for MCQ examinations.
- Identify concepts requiring detailed written explanations.

However, do not limit educational notes to previously asked questions. Notes must provide sufficient conceptual coverage to help learners answer unfamiliar questions too.

## 7. Content Research and Copyright Guidelines

Reference websites are research sources, not content templates to copy.

Claude must:

1. Understand information from the references.
2. Combine information from multiple sources where appropriate.
3. Explain concepts using original wording.
4. Create original examples when helpful.
5. Write clear and structured educational explanations.
6. Avoid copying paragraphs, diagrams, or explanations verbatim.
7. Avoid reproducing copyrighted content.
8. Create original diagrams where possible.
9. Attribute external sources appropriately.
10. Maintain a record of sources used for each topic.

Do not translate an entire source article word-for-word into Bengali. Create original Bengali explanations that preserve technical accuracy and meaning.

## 8. Bilingual Research and Writing

Research may use English-language sources, but final notes must be independently written in both English and Bengali.

### English notes

- Use clear and grammatically correct English.
- Prefer standard technical terminology.
- Explain concepts step by step.
- Use appropriate examples and technical vocabulary.

### Bengali notes

- Use natural and understandable Bengali.
- Retain standard English technical terms where appropriate.
- Explain difficult concepts in Bengali.
- Avoid awkward literal translations of technical terminology.
- Maintain the same depth, meaning, and topic coverage as the English version.

Both language versions must be technically consistent.

## 10. Source Status Definitions

Use these statuses consistently:

- **Not Added:** No reference URL has been added yet.
- **Pending Review:** URL has been collected but not fully reviewed.
- **Verified:** Source has been opened, reviewed, and considered useful for the topic.
- **Inaccessible:** Source could not be accessed.
- **Not Relevant:** Source was accessible but did not provide useful information for the topic.

Do not mark a source as Verified merely because its URL exists.
